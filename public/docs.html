🤖 Designed for AI Agents & LLMs

Grima exposes network telemetry formatted for seamless consumption by AI agents, automation pipelines, and smart home managers. Agents can read the raw Markdown instructions at /llms.txt or parse the standardized /docs/openapi.json spec.

POST GET /api/speedtest New in v0.3.0
Open Live Output ↗
Performs an on-demand network speed test against the nearest Cloudflare Edge. Measures download throughput (Mbps), upload throughput (Mbps), latency (ping), and jitter in ~1.5s without external dependencies. 
# Run on-demand test:
curl -X POST http://localhost:3000/api/speedtest

# Retrieve last cached result:
curl -s http://localhost:3000/api/speedtest
GET /api/status
Open Live Output ↗
Returns complete aggregated network telemetry: summary counts, active devices inventory, Wi-Fi spectrum, router gateway state, latest speed test, latencies, and host machine stats. 
curl -s http://localhost:3000/api/status
GET /api/devices
Open Live Output ↗
Returns list of all active network nodes on the local subnet (/24) including IP, MAC address, manufacturer from IEEE OUI database, friendly name (SSDP/UPnP), connection medium (Wi-Fi vs Wired), and ping RTT. 
curl -s http://localhost:3000/api/devices
GET /api/wifi
Open Live Output ↗
Returns Wi-Fi radio status and nearby networks scanned via the wireless adapter (SSIDs, BSSIDs, carrier frequencies, channels, signal percent & dBm, and security suites). 
curl -s http://localhost:3000/api/wifi
GET /api/router
Open Live Output ↗
Returns router and gateway diagnostics queried via UPnP IGD: router model, external public WAN IP, system uptime, and connection status. 
curl -s http://localhost:3000/api/router
POST /api/scan
Invalidates cached scan data and triggers an immediate active ARP sweep and Wi-Fi spectrum scan. 
curl -X POST http://localhost:3000/api/scan
GET /api/version
Open Live Output ↗
Returns daemon name, version, and metadata. 
curl -s http://localhost:3000/api/version
